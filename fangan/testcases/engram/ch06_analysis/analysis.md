## v0.3.3 change note (relative to v0.1)

Knowledge content (atom/chunk/object/relation IDs and meaning) is preserved; it is re-expressed in
the v0.3.3 schema with verbatim spans added. Final counts:
**44 atoms / 40 source_elements / 7 chunks / 7 packages / 21 objects / 20 relations / 24 mentions.**

- **Dual coordinates**: every atom carries `source_span` (authoritative, file=`engram_paper_mineru.md`,
  with line/char) + `viewer_span` (`viewer_only:true`, file=`source.md`); both slices equal `raw_text`.
  `build.py` locates each span by verbatim substring search inside the 224-321 window and asserts
  `source_file[span]==raw_text` and `source.md[span]==raw_text`.
- **raw/normalized discipline**: `raw_text` is a verbatim contiguous span; `normalized_text` renders only
  that span (LaTeX/Unicode -> ASCII: `X^T`, `a_j`, `alpha_t`, `->`, `29-44%`; Chinese -> pinyin
  `sida famming`/`Zhang Zhongjing`; in-span pronouns resolved), no out-of-span facts/section-refs.
  Formula atoms (`A-CKA-EQ8`/`A-CKA-EQ9`) are formula-only; their symbol interpretation is supplied via
  `metadata.supported_by_context_atoms` (`A-CKA-METHOD` / `A-CKA-AINDEX`).
- **Object evidence local/supporting + home_package**: objects split `local_evidence_atom_ids`
  (inside the home_package chunk) + `supporting_context_atom_ids` (from other chunks). Two **cross-package**
  objects: `MECH-EFFECTIVE-DEPTH` (home `PKG-EFFECTIVE-DEPTH`/6.1.2, supporting `A-DEPTH-HYP`+`A-LL-INTERP`
  from 6.1.1) and `COMP-GATING` (home `PKG-ABLATION`/6.2, supporting `A-CASE-SETUP` from 6.5).
- **One package per chunk**: 7 chunks -> 7 packages, `package.atoms == chunk.atom_ids`, `expected_objects`
  per package; `expected_local_fields` declared on `PKG-DEPTH-LL` (partial `MECH-EFFECTIVE-DEPTH`) and
  `PKG-CASE` (partial `COMP-GATING`).
- **Labels**: removed all decimal `confidence`; objects/relations use
  `gold_label:true` + `difficulty`(easy/medium/hard) + `evidence_strength`(direct/indirect/cross_reference).
- **Relations re-typed to the spec vocabulary**: `formula_defines_metric` (v0.1) is replaced by
  `component_defined_by_formula` (R-03/04) + `formula_generalizes_formula` (R-05); `experiment_uses_setup`
  is replaced by `experiment_tests_claim` (R-10/11/12/16); added `system_design_has_tradeoff` (R-17) for the
  conservative-baseline caveat. Endpoints all resolve to `objects`.
- **New objects to absorb formerly-orphan atoms**: `RESULT-ENTITY-RESOLUTION` (Table 3 + `A-DEPTH-MOTIV`)
  and the `LogitLens`/`CKA` tool sentence folded into `MECH-CONVERGENCE`; Table 4 header/setup rows fold
  into `SETUP-THROUGHPUT`. Global no-orphan now holds (every atom feeds an object or relation).
- **Tables**: Table 3 (line 242) and Table 4 (line 312) are single-line HTML `<table>` blocks; rows are
  captured as anchored `<tr>...</tr>` substrings (`A-T3-*`, `A-T4-*`). Table 4's `colspan`/`rowspan` is
  reassembled into per-backbone baseline-vs-offload rows.
- **do_not_extract**: inline author-year citations (3 anchored + a `citation_policy`), the transliterated
  Chinese tokens `四大发明`/`张仲景`, and the out-of-slice section refs `Section 2.5`/`Section 2.3`.
- **source_elements**: auto-generated (8 headings + 32 content elements); prose paragraphs split by inserted
  floats (Table 3/Figure 5/Figure 6/Table 4) carry a `metadata.note` recording the line split.
