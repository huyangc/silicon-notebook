# silicon-notebook 用户使用手册

[返回 README](../README_zh.md) · 产品行为的精确定义以[产品与 API 参考](./product-and-api_zh.md)为准

这份手册写给**在浏览器里使用 silicon-notebook 的人**，不写给部署或开发它的人。
它不讲安装、配置和接口，只讲你在界面上能看到什么、能做什么、每一步会发生什么。
安装与部署请看[部署与配置](./deployment-and-configuration_zh.md)。

在已部署的系统里，这份手册的地址是 `/manual`（头像菜单里的「使用手册」也指向它），
不需要登录就能打开。

手册按「先上手、再深入、最后越用越好」的顺序组织。第一次使用，读完第 1–4 章就能开始工作；
第 5–10 章讲问答模式、全局问答、知识图谱、记忆与 Knowhow、深度报告、分享与群组这些进阶功能；
第 11 章讲系统如何越用越好；第 13 章是常见问题。

## 1. 这是什么

silicon-notebook 是一个**基于你自己资料回答问题的知识笔记本**。你把 PDF、Word、PPT、
Excel、Markdown 等文档放进一个笔记本，然后用自然语言提问；系统在这些文档里检索、
组织证据，给出**每一句都能点开看出处**的回答。它面向半导体工程团队设计，但对任何
需要「从一堆资料里找答案」的场景都适用。

它和普通聊天机器人的区别有三点：

- **只根据你给的资料回答。** 回答里的每个结论都带引用，点开就是原文段落；证据不够时它会明说，
  并把推测标成「（推断）」，而不是编一个答案。
- **资料会被整理成结构化知识。** 除了原文，系统还会从文档里提炼概念、论断、公式和步骤，
  组成知识图谱，用于更深入的推理。
- **成果可以沉淀、可以共享。** 好的回答可以存成「记忆」，经验可以整理成 Knowhow 表，
  复杂问题可以生成多章节的深度报告；笔记本可以分享给同事或整个群组。

### 几个会反复出现的词

| 词 | 意思 |
| --- | --- |
| 笔记本 | 一组资料加上围绕它的问答、知识和报告。你可以有很多本，每本独立。 |
| 来源 | 放进笔记本的一份文档。上传后系统会解析它、拆成段落并分析。 |
| 问答 | 在笔记本里提问、得到带引用的回答。支持多轮追问。 |
| 知识图谱 | 系统从来源里分析出来的概念、论断、公式、步骤及它们之间的关联。 |
| 记忆 | 你手动保存下来的回答，只有你自己看得见，之后的问答会优先参考。 |
| Knowhow 表 | 一张你自定义列名的经验表，比如「违例类型 / 现象 / 根因 / 修法」。 |
| 深度报告 | 针对一个研究问题生成的多章节技术报告，每章都有引用。 |
| 参考库 | 挂到当前笔记本上的其他笔记本。提问时会一并检索它们的内容。 |
| 公共知识库 | 由管理员发布、所有人都可以挂为参考库的笔记本。 |
| 群组 | 一组用户。把笔记本共享给群组，组内成员就都能读它、在里面提问。 |

## 2. 登录与首页

### 2.1 注册与登录

打开系统地址，先看到登录页。

- **注册**：切到「注册」页签，填用户名和密码。用户名规则固定为**一个小写字母加八位数字**，
  例如 `a12345678`。
- **登录**：填用户名和密码后点登录。
- **统一认证**：如果管理员开启了公司统一认证，登录页只有一个「使用{名称}登录」按钮
  （{名称}是部署配置的统一认证名称），没有用户名密码表单，也不能自助注册。工号与本站
  某个账号的用户名完全一致时直接进入；对不上时，首次登录会进入一个选择页：
  - **关联老账号**：输入本站老账号的用户名和密码，老账号改用工号登录，原来的笔记本等数据都在；
  - **使用新账号**：以工号新建一个账号，老账号的数据不会出现在新账号里。

  选错了（误选了新账号）不能自己改回，请联系管理员。忘了老账号密码，也请管理员先帮你重置。
- 首次搭建的系统自带一个 `admin` 管理员账号；普通使用者不需要它。

### 2.2 首页长什么样

登录后进入笔记本列表页，这是所有工作的起点。

- **顶部三个页签**：「全部」「我的笔记本」「精选笔记本」。「精选笔记本」只列出已经有内容的
  笔记本，帮你跳过空库。
- **工具栏**：搜索框可以搜笔记本名、来源名甚至来源里的内容；旁边可以切换卡片或列表视图，
  按「最近创建」「名称」「来源数量」排序。
- **「＋ 新建」**：点一下立刻创建一本叫 `Untitled notebook` 的笔记本并进入，没有弹窗。
  标题稍后可以在笔记本里直接改，也可以不改：上传文档后系统会根据内容自动起标题和描述，
  你手动改过的字段系统不会再动。
- **「已分享」按钮**：查看你分享出去的所有笔记本，以及谁通过链接加入了。
- **「导入」按钮**（在「＋ 新建」旁边）：把导出的笔记本文件（`.snbk`）导入为一本新的笔记本，见第 3.7 节。

列表分成两个区：

- **我的笔记本**：你自己创建的，以及通过分享链接加入的。通过链接加入的会标「只读 · 来自某某」，
  旁边有「退出共享」。
- **群组**：别人通过群组共享给你的。卡片标「只读 · 来自群组《X》」或「可管理 · 来自群组《X》」。
  这类笔记本由组管理员管理，所以没有「退出共享」按钮。

### 2.3 右上角的头像菜单和铃铛

头像菜单里有几个全局入口，后面各章会用到：

- **高级模式**开关：见第 5 章。
- **私有记忆**：你在所有笔记本里保存的记忆汇总，见第 8 章。
- **我的回答偏好**：设置回答语言、组织方式、详略，见第 11 章。
- **群组**：管理你所在的群组，见第 10 章。
- **Agent 接入**、**许愿墙**：见第 12 章。

铃铛是**待确认中心**。它汇总需要你处理或值得你知道的事：正在进行的提问、等你确认的深度报告、
等你审批的共享申请、知识治理待办、索引与论文信息补全的进度，以及「导出与导入」的进度（见第 3.7 节）。
点一条就跳到对应位置。

## 3. 上传文档

### 3.1 进入笔记本

从首页点开一本笔记本，界面分三块：

- **顶栏**：左边是可编辑的笔记本标题；右边一排动作：「创建笔记本」「分析」「看板」「知识图谱」
  「Knowhow 表」「分享」「模型服务」「设置」。其中「分析」和「分享」只有笔记本的管理者才看得到。
- **左栏**：来源列表。上传、查看、删除文档都在这里，也是勾选检索范围的地方；
  「AI 对这个库的理解」按钮也在这一栏（第 11 章）。
- **主栏**：四个页签，「问答」「知识库」「记忆」「深度报告」。

### 3.2 添加来源

点左栏的「添加来源」，弹窗里有两个入口：

- **上传文件**：选文件或直接拖进来。支持 PDF、Markdown（`.md`）、Word（`.docx`）、
  PowerPoint（`.pptx`）、CSV、Excel（`.xlsx`、`.xlsm`、旧版 `.xls`），以及**含图片的 Markdown 压缩包**（`.zip`）。
- **添加链接**：粘一个可以直接下载的 PDF 链接。不是 PDF 的链接会被拒绝。

弹窗会写明单个文件的大小上限和一次最多能传几个，以实际提示为准。不合规的文件不会被悄悄
丢掉，而是逐条列出文件名和原因，常见的有：

- 旧版 Office 格式（`.doc`、`.ppt`）不支持，请另存为 `.docx` / `.pptx` 后再传。
- 文件类型不支持。
- 超过单个文件大小上限，或这一批超过了笔记本剩余的文档名额。

**Markdown 里有图片怎么办？** 单独上传一个 `.md` 文件时，如果它引用了本地图片，弹窗会提示
「检测到 N 个本地图片引用……问答中将无法展示」。要让图片进来，把 Markdown 和图片一起打成 `.zip`
上传，或者把整个文件夹拖进弹窗；上传后会有一份「图片配对结果」告诉你哪些图片找到了、哪些没有。

### 3.3 上传之后发生了什么

上传是后台处理的，你可以继续做别的事。左栏每份来源都有一个状态：

| 状态 | 意思 |
| --- | --- |
| 已上传 / 排队中 / 解析中 | 系统正在把文档转成可检索的内容。 |
| 已解析 | 正文已经可以用于问答。 |
| 分析中 / 已就绪 | 正在或已经把内容整理进知识图谱（只有笔记本开启了知识图谱时才有这一步）。 |
| 解析失败 | 文档没能读出来。点开来源详情看原因，通常是文件损坏或加密。 |
| 仅元数据 | 只拿到了标题等信息，没有正文。 |

来源名旁边可能出现小徽标：**红色**表示这份文档有问题（比如解析失败），**黄色**表示部分内容没能
分析、可能影响检索。点开来源能看到细节。

对 PDF、Word、PPT 这类格式，如果你们的部署配置了高精度解析服务，公式、表格、图片都会被保留；
没有配置时会用内置解析器，文字仍然完整，但版面复杂的扫描件效果会差一些。

### 3.4 查看、重新解析、删除

点来源名打开**来源详情**，可以按段落浏览解析出来的内容、公式和图片。详情页里可以：

- **重新解析**：文档更新了解析器、或者上次解析质量不好时用。会替换这份来源解析出来的所有内容，
  但不删除文件本身。
- **删除**：删掉这份来源和它产生的一切内容。

### 3.5 「整理知识图谱」和「补全论文信息」

左栏「添加来源」下面：

- **知识图谱那一句**：说明这本笔记本的知识图谱现在怎样，句子里的「整理知识图谱」就是按钮，点一下
  让系统从所有来源里提炼概念、论断、公式、步骤，建成知识图谱。这一步要调用模型，文档多时会跑一会儿。
  第一次整理后再新增来源，这句会变成「知识图谱已就绪 · N 篇新来源待分析，分析并合并」，点「分析并合并」即可。
  没挂参考库时，库主还能直接点句子里的「挂载已整理的参考库」。没有知识图谱也可以正常问答；知识图谱
  主要让「逐步推理」能沿着关联找证据，并让知识库页签有内容可看。
- **补全论文信息**：在一排小按钮里（只在有论文信息不全时出现），对论文类文档自动补齐标题、作者、
  年份等信息，让引用和报告参考文献更完整。「AI 对这个库的理解」和管理员装的插件入口也在这一排。

「看板」按钮打开「索引与构建」面板，能看到解析、索引和知识图谱三条线的整体进度，文档很多时可以在这里
确认后台是否都跑完了。

### 3.6 笔记本设置

顶栏「设置」打开笔记本设置（首页卡片菜单里的「编辑信息」打开的也是它），主要几段：

- **基本信息**：标题、描述、领域关键词。
- **索引管线**：默认「内建」即可，除非部署方提供了自定义管线。
- **参考库**：勾选要挂到这本笔记本上的其他笔记本，提问时会一并检索它们。候选分三组：
  「公共知识库」「我的笔记本」「共享给我的」。不选就只搜本笔记本。参考库的更多说明见第 10.6 节。
- **导出**：只有笔记本的主人看得到。把整本笔记本导出成一个文件，见下一节。

### 3.7 导出与导入笔记本

把一本笔记本导出成一个 `.snbk` 文件，就可以在本系统或另一套部署里把它导入为**一本新的笔记本**：它归导入的人
所有，可以照常编辑，与原来那本此后互不影响；同一个文件可以导入多次，每次都是新的一本。

**文件里有什么。** 原文件、知识图谱、经验表（Knowhow 表）与检索数据。**不包含**你的记忆、问答记录与深度报告，
也不带成员、共享设置、分享链接和挂载的参考库。记忆需要的话可以另外导出（见下文）。

**导出（只有笔记本的主人能导出）：**

1. 在笔记本里点顶栏「设置」（或在首页卡片菜单点「编辑信息」），找到最下面的「导出」一节。同步来的镜像笔记本
   没有设置弹窗，在首页它的卡片菜单里点「导出笔记本」。
2. 点「导出笔记本」。导出在后台进行，关掉窗口不影响它；完成后也可以在右上角铃铛的「导出与导入」里下载。
3. 显示「导出完成：…」后点「下载」，浏览器会把文件存到下载目录。导出文件保留一段时间，期限写在「…前可以下载」里；
   期限内可以再次下载，过期后需要重新导出。点「重新导出」会生成新的文件并替换掉上一份。
4. 导出文件不包含记忆。需要的话，点同一节里的「导出我的记忆（Markdown）」另外保存一份。

网页导出有大小上限（「导出」一节里写着「网页导出上限 … MB」）。笔记本的原文件超过它时会提示
「这本笔记本的原文件已超过网页导出上限（… MB），请联系管理员用命令行导出。」，请找管理员帮你导出。

**导入（所有登录用户都可以）：**

1. 在首页工具栏点「导入」，打开「导入笔记本」窗口。
2. 在「导出文件」里选一个 `.snbk` 文件。「新笔记本名称」可以不填，留空则沿用导出时的名称。
3. 点「开始导入」。按钮会依次显示「正在准备…」「上传中 N%」「正在检查文件…」；上传途中可以点「停止上传」。
   文件传完之后就停不下来了，导入会在服务器上继续。关掉窗口不影响上传和导入：上传还没完成时，工具栏的「导入」按钮
   显示「导入中…」；传完之后它恢复成「导入」，导入的进度在「导入记录」和右上角铃铛里看。
4. 进度和结果在窗口下方的「导入记录」里。导入完成后点「打开笔记本」。导入中的那一行可以点「取消导入」，已经结束的
   可以点「移除记录」（只移除记录，不删除导入好的笔记本）。

笔记本生成之后就会出现在你的笔记本列表里，可以打开使用；随后系统在后台核对并**补全检索数据**（文件里缺的就补上，
已经齐全的很快结束）。这段时间里提问可能找不全相关内容：「导入记录」里写「笔记本已经导入，可以打开使用；后台正在
补全检索数据，完成前提问可能找不全相关内容。」，铃铛里显示「已导入，正在补全检索数据」，完成后自动恢复。

导入完成后，「导入记录」还会把需要你处理的事写在那一行下面：导出时还没处理完的文档，导入后需要在笔记本里重新解析；
原笔记本挂载的参考库没有一起带过来，需要的话请重新挂载；有 Knowhow 表没有同步完成时，打开那张表点「重新同步」；
后台补全检索数据没有完成时，按记录里的提示处理（见下表）。

**限制。**

- 网页导入同样有大小上限（窗口里写着「网页导入上限 … MB」）。
- 每个人同时进行的导出和导入有数量上限，超出时会提示「你已有 2 个导出或导入正在进行，请等其中一个完成后再试。」
- 不是管理员的用户，导入文件里的文档数不能超过每本笔记本的文档上限。

**遇到提示怎么办：**

| 提示 | 怎么办 |
| --- | --- |
| 请选择笔记本导出文件（.snbk）。 | 选错了文件，换成导出的 `.snbk` 文件。 |
| 导入文件超过网页导入上限…，请联系管理员用命令行导入。 / 这个文件解压后过大… | 文件太大，网页导不了，请管理员用命令行导入。 |
| 这个文件的文档超过每本笔记本最多 N 篇的上限… | 请管理员导入，或请管理员调整你的文档上限。 |
| 你已有 2 个导出或导入正在进行… | 等其中一个完成后再试。 |
| 这个文件无法导入：它不是笔记本导出文件，或者已经损坏。 | 重新下载或重新导出一份再导入。 |
| 这个文件来自更新版本的部署，请先升级本部署再导入。 | 文件本身没问题，是本系统版本较旧；请管理员升级后再导入。 |
| 导入中断了，请重新导入。 / 服务重启，这次导入没有完成，请重新导入。 | 什么都没有留下，重新导入即可。 |
| 笔记本已经导入，但后台处理没有完成，部分检索可能不全… / 服务重启时笔记本已经导入，但后台处理没有完成… | 这次导入记为失败，但笔记本已经在列表里了，**不要再导入一份**。删除这本笔记本后重新导入；也可以请管理员按运维手册把缺的部分补上。 |
| （导入完成）后台补全检索数据没有完成，提问可能找不全相关内容；打开笔记本后在「看板」的「来源状态」里点「补齐向量」补上检索数据。 | 照做即可补上。 |
| （导入完成）后台处理没有完成，部分检索可能不全；可以删除这本笔记本后重新导入。 | 删除这本笔记本后重新导入，或请管理员把缺的部分补上。 |
| （导入完成）后台仍在补全检索数据，完成前提问可能找不全相关内容。 | 等它完成即可，不需要做什么。 |
| （导入完成）有 N 张 Knowhow 表没有同步完成… | 打开笔记本，在「Knowhow 表」里打开那张表，点「重新同步」。 |
| 连接中断，导入可能已被接收… | 先看「导入记录」里有没有这次导入，没有再重传。不重新选文件、直接再点「开始导入」重传，不会多出一本。 |
| 上一次上传的这个文件还在处理中，请稍后查看导入记录。 | 等一会儿，再看「导入记录」。 |

**铃铛。** 右上角铃铛的「导出与导入」组里能看到进行中的导出和导入、完成但还没下载的导出（行内有「下载」）、
已经导入但还在后台处理的笔记本（行内有「打开笔记本」），以及失败的记录。导入成功后就不再出现在铃铛里。

## 4. 开始提问

### 4.1 第一次提问

进入「问答」页签。没有对话时，页面会显示笔记本的描述，以及最多四个**推荐问题**按钮，
按钮是根据你的文档内容生成的（标注「根据来源内容推荐」；文档太多只取样了一部分时标注
「根据部分来源内容推荐」）。点一个，或者在下方输入框里自己写，回车发送。

发送后，问题立刻上屏。回答是流式出现的；如果用的是「逐步推理」引擎，回答上方会实时显示
系统正在做什么（理解问题、检索、反思、回答），每一步都可以展开看细节。
右侧的**停止**按钮（一个方块图标）随时可以中断。

### 4.2 读懂回答

回答里有几种你会经常看到的东西：

- **引用标记**，形如 `[k1]`。点一下，标记旁弹出**引用卡片**：被引的原文段落、它来自哪份来源、
  在文档的什么位置。卡片上可以跳到来源详情看上下文。如果那段原文带图（比如论文里的图表），
  卡片里会有「本段附图」，回答正文里也会内联显示。
- **「（推断）」标签**：这句话是系统根据证据推测的，证据本身没有直接说。凡是依赖推断的结论也会带上这个标签。
- **「【通识】」标签**：这句话是常识性背景，不来自你的文档。
- **警示条**：当证据不足以支撑回答时，回答顶部会明确提示，即使回答里有几条引用也不会隐藏这个提示。
- **Excel 分析卡片**：如果问题涉及你上传的 Excel 表格并且用的是「逐步推理」，回答里可能出现一张结果卡，
  标明做了什么（数据概况、分组汇总、排序、筛选）、结果是否完整，并能点「查看来源」。
- **文档目录卡片**：问「这个库里的文档分别讲了什么」这类问题，回答会附一张按文档列出的卡片，
  每篇给标题、类型和摘要。

回答下方有几个按钮：

- **复制**回答正文。
- **有帮助 / 没帮助**（大拇指图标）。反馈会被记录下来，管理员据此发现答得不好的问题。
- **保存到记忆**：把这条回答存起来，见第 8 章。

### 4.3 多轮追问与会话

同一个会话里可以连续追问，系统会结合前面的问题理解你现在问的是什么。

会话管理在问答面板顶部：可以新建会话、在历史会话之间切换、重命名或删除。每个会话都是独立的
上下文；换话题时建议新开一个会话，回答会更准。收起左侧来源栏后，历史会话会从顶部的「历史」按钮
展开、平铺在左栏，一行一个标题，点一下就切换；把鼠标移到某一行上会出现分享、重命名和删除。新会话
入口也一起移到左栏顶部——页面上始终只有一处会话入口。重新展开来源栏时，会话栏缩回「历史」按钮。

**离开页面不会丢掉正在进行的提问。** 刷新或关掉页面后再回来，回答会接着显示；正在进行的提问
也会出现在铃铛里，点一下就能回到那个会话。

**就某份报告追问。** 想接着一份深度报告往下问时，在报告详情上方点「就此追问」（只有已完成的报告有这个
按钮），或者在左边来源栏的「关联报告」一组里点「选择」，在展开的列表里挑一份——这里只列出你在这个笔记本里
生成完成的报告。挂上之后，这一组里出现报告题目的标签。回答会读这份报告，并回到报告引用过的
原文去找依据；报告里的某个说法在当前资料中找不到依据时，回答会直接说出来。标签在这个会话里一直有效，之后
每次提问都会带上，直到你点标签右侧的「移除关联报告」或换一份；重新打开这个会话时标签也会回来。

用「就此追问」打开时会开一个新会话。在高级模式下，左栏的检索范围还会勾成报告生成时用的范围：已经不在的
资料或参考库会略去，标签旁有一句说明；无法按原样勾选时改为全选，同样会说明。

有时这一轮不会读这份报告，例如报告引用的资料或参考库这次没有勾选，或者报告用到了你的个人记忆、而你
收窄了检索范围。这时标签会变灰，旁边直接写出原因，调整勾选后再问即可；回答照常给出。

每一轮回答上方都会写明「关联报告《题目》」这一轮读了什么——读了全文还是哪几节、复原了多少条引用证据，没读
的话写明原因，点开能看到每一节的情况。用「逐步推理」时，推理过程里也多一步「报告」。会话历史里，最后一轮
挂着报告的会话带「关联报告」标记。

### 4.4 精确匹配某个短语

问题里用**英文半角双引号**括起来的内容会被当成一个整体去找，比如
`什么是 "static timing analysis" 的原理`。这会让包含这段原话的文档排在前面，但不会把
没有这段原话的文档排除掉。找特定术语、器件型号、函数名时很有用。

### 4.5 给问答设定范围

左栏每份来源前面有复选框，默认全选。取消勾选某些来源后，这次提问只在勾选的来源里找证据，
连挂载的参考库也在同一个面板里按整库勾选。工具条上显示「检索范围 · 本库 N/M · 参考库 K/L」，
「全选」「清空」一键操作。这个范围同时作用于问答和新建深度报告。

注意：自动模式下这些复选框是隐藏的，需要切到高级模式（见下一章）才能用。

## 5. 问答模式：自动、高级、通用问答与逐步推理

这一章解释你在问答里能调的几个开关。如果只是想尽快用起来，记住一句话就够了：
**默认的自动模式已经选好了大多数人需要的配置，不调也能用。**

### 5.1 自动模式与高级模式

这是一个账户级开关，在头像菜单里的「高级模式」。

- **自动模式**（默认）：问答页面只有一个输入框。系统固定用「逐步推理」引擎和「标准」检索档位，
  来源范围默认全选。
- **高级模式**：问答输入框旁多出引擎选择和检索档位，深度报告页签多出研究深度，左栏出现来源和参考库的勾选框。

什么时候需要高级模式？想缩小检索范围、想换更快或更深的引擎、想调报告深度、想在深度报告生成前
自己确认问题理解和章节结构的时候（自动模式下报告是一键直接生成的，见第 9.1 节）。

### 5.2 两种引擎：通用问答与逐步推理

高级模式下，输入框旁可以选引擎：

| 引擎 | 怎么工作 | 适合 |
| --- | --- | --- |
| 通用问答 | 一次性大范围检索原文段落，选出最相关的，综合成回答。快，不需要知识图谱。 | 事实查找、「文档里怎么说」、介绍某篇文档 |
| 逐步推理 | 先理解问题，再一轮轮检索、反思、补检索，直到证据够了才回答。会显示每一步。有知识图谱时还能沿关联扩展。 | 需要综合多份资料、比较、列全清单、分析 Excel 表 |

「扩展功能」分组里是部署方额外接入的引擎，没有就不会显示。

### 5.3 逐步推理的检索档位

「逐步推理」可以选检索力度，五档：**概览、标准、深入、详尽、穷尽**。档位越高，检索轮数越多、
读的证据越多，回答越全面，但也越慢、越费模型。日常用「标准」；要求「列出所有」「一个都别漏」
的问题用「详尽」或「穷尽」。「穷尽」档还会让系统边检索边维护一份大纲，最后按大纲分节作答。

这五个档名和深度报告的「研究深度」是同一套，含义一致。

### 5.4 「先补充问题信息」卡片

用「逐步推理」提问时，系统会先**不读任何资料**、只根据问题本身理解你要什么。问题清晰就直接开始检索；
问题有歧义、且不同理解会导致完全不同的答案时，会弹出一张「先补充问题信息」卡片：

- 列出系统的理解（研究类型、涉及对象、比较维度、约束等），标出「待你确认」的几项；
- 你补充或修改后点「确认并开始检索」，或者「返回修改」重写问题。

这一步的目的是别让系统在错误的方向上跑很久。卡片不会每次都出现，只在真有歧义时出现。

### 5.5 「介绍这个库」和「介绍某篇文档」

这两类问题有专门的处理：

- 「这个库里的文档分别介绍了什么」：系统直接按文档目录逐篇给出标题、类型和摘要，不需要知识图谱。
- 「介绍一下《某篇完整标题》」：系统按顺序取样这篇文档的正文来介绍。文档很长时会说明只读了一部分。

问的时候把文档标题写完整，标题有歧义时系统会请你缩小来源范围而不是猜。

## 6. 跨笔记本的全局问答

想一次在多本笔记本里找答案，用**全局问答**。入口是首页和笔记本页右下角的气泡，点开是一个小聊天窗，
可以放大成整页；也可以直接访问 `/ask`。

- **选笔记本**：范围选择器可以选「全部可访问的笔记本」或勾具体几本。一次最多检索 8 本；
  你能读的笔记本不超过 8 本时默认全选，超过时系统先预选来源最多的 8 本，你可以改。
- **提问方式**和笔记本内一样，同样可以选「通用问答」或「逐步推理」。回答会标明每条引用来自哪本笔记本，
  点引用卡片上的「打开笔记本」可以跳过去看原文。
- **进度**：跨库检索会逐库显示进度，中途停止也保留已完成的部分。
- **会话**：左侧「最近对话」列表可以切换、重命名、删除。通过 Agent 接口发起的对话也在这里。
- **分享**：一条已完成的全局会话可以生成免登录的只读链接（第 10.7 节）。

全局会话不属于任何笔记本，也不会创建新笔记本。缩小范围后，之前在更大范围里得到的回答不再作为
后续追问的上下文，界面会提示这一点。

## 7. 知识库与知识图谱

这一章是可选的。不整理知识图谱也能正常上传和问答；整理之后，「逐步推理」能沿着知识之间的关联找证据，
你也能直接浏览系统提炼出来的知识。

### 7.1 「知识库」页签

主栏「知识库」页签按类型列出知识图谱里的条目：**概念、论断、公式、流程**，以及由 Knowhow 表生成的
自定义类型。每一条都能展开看出处（来自哪份来源的哪一段）。这里也是知识治理的入口：
重复的条目会被归为「重复组」，可以合并。

### 7.2 知识图谱视图

顶栏「知识图谱」打开全屏视图。画布上不同形状代表不同类型的知识对象，连线是它们之间的关联。
点一个节点，右侧显示它的相邻关系、定义、流程步骤、出处和相关节点。

左栏从上到下：

- **图谱处理**：几个后台动作。「补上关联」给没建立关联的内容补连线；「重新合并」重新做跨文档的概念归并；
  「全部重新分析」把所有来源重新过一遍（耗时较长）；「删除知识图谱」清掉从来源分析出的图谱，
  来源和解析内容都保留，记忆和 Knowhow 表产生的知识不受影响。删除前会二次确认。
- **当前视图** 和 **类型过滤**：限定画布显示的范围和类型。
- **待确认合并**：系统发现的跨文档同义概念，逐条「合并」或「拒绝」，也可以「自动判重」让模型先筛一遍。

视图头部还有「图谱分析」和「图谱 Schema」。前者给出一份可读的体检报告：这张图谱可信度如何、哪些类型
合并信号强、主题结构怎样、第一个值得复核的来源是哪份。后者是管理员定义知识对象类型的地方。

### 7.3 「分析」菜单

顶栏「分析」按钮（管理者可见）里有三样：

- **内容审核**：审批「贡献到公共知识库」的申请，见第 10.8 节。
- **发布 / 撤回公共知识库**（管理员）：把这本笔记本发布成所有人都能挂为参考库的公共知识库。
- **关系审核队列**：系统按风险排序列出可信度存疑的关联，人工确认或拒绝。被拒绝的关联不再参与推理。

## 8. 沉淀成果：记忆与 Knowhow 表

### 8.1 记忆：把好的回答存下来

在任何一条回答下点**保存到记忆**：

1. 系统先生成一份预览：标题、正文、标签。你可以改。
2. 如果这本笔记本已经开启了知识图谱，预览里会有一个默认勾选的「同时抽取到知识图谱」；
   勾上后这条记忆也会被分析进图谱。
3. 点确认，写入。回答的引用会一起保存，记忆卡片上能看到出处并跳回原文。

记忆的几条规则：

- **只有你自己看得见**，即使笔记本是共享的。
- **绑定当前笔记本**。之后在这本笔记本里提问，已确认的记忆会作为优先证据参与。
- 主栏「记忆」页签看当前笔记本的记忆；头像菜单里的「私有记忆」看你所有笔记本的记忆。
- 外部 Agent（第 12.1 节）可以替你提交**候选**记忆，但候选不会参与问答，直到你在记忆页确认它。

### 8.2 Knowhow 表：把经验整理成表

顶栏「Knowhow 表」打开一个独立面板。它适合沉淀「一行一个案例」的经验，
比如时序违例排查：行是违例类型，列是现象、根因、修法、用到的工具。列名完全由你定。

- **建表**：新建空表自己定表头，或者从 Excel / CSV / Markdown 导入。表管理弹窗里能「按当前表头下载
  Excel 模板」，线下批量填好再「追加导入」。
- **行标题列**：可以指定一列作为整张表的行标题。设置后，表里每个格子都会成为知识图谱里的一个知识对象，
  问答命中格子时会直接跳到那一行的详情。
- **列的内容类型**：普通、方法步骤、工具/事物。它只影响格子怎么被拆成知识对象，不调用模型。
- **优化表达**：格子编辑器里的按钮，让模型在不改原意的前提下把表述整理通顺。只在你点的时候才执行。
- **智能补全空列**：在行详情里，让模型参考同表其他行和笔记本里的资料，给这一行还没填的格子提建议。
- **历史**：每个格子的修改历史都能查看和回退。

Knowhow 表的内容会自动参与问答检索，也会随笔记本一起被拷贝。

## 9. 深度报告

当一个问题需要的不是一段回答、而是一份有章节、有引用、有参考文献的技术报告时，用深度报告。

### 9.1 生成一份报告

**自动模式下**（默认），流程只有一步：进入「深度报告」页签，写下研究问题（最多 4000 字），
点「生成深度报告」。系统先不读资料、只理解问题；问题清晰就直接规划章节并开始生成，中间不停下来
问你。只有问题存在阻断性歧义时才会停在「补充问题信息」卡片上，等你回答后继续。生成是后台任务，
可以离开页面；报告进度也在铃铛里。

**想自己把关问题理解和章节结构**，先在头像菜单里打开「高级模式」（第 5.1 节），再提交。这时流程变成：

1. 写下研究问题，可以调**研究深度**（概览 / 标准 / 深入 / 详尽 / 穷尽，与第 5.3 节同一套档位）。
   左栏勾选的来源和参考库范围同样生效。
2. 点「生成深度报告」。系统给出一张「确认问题理解」卡片：最终研究问题、必须回答的要点、研究对象、
   比较维度、约束、不纳入范围的内容、成立前提、期望输出。你可以改，有阻断性歧义时必须先回答。
3. 确认后系统规划**分析框架**，也就是报告的章节结构。你可以增删章节、调整顺序、改每一节的
   「本节范围」和「检索方向」。对比较、综述类问题，框架还会给出可编辑的比较维度。
4. 点「生成完整报告」。

报告状态依次是：排队中 → 规划中 → 待确认问题 / 待确认 → 生成中 → 完成。生成过程中能看到
每一节走到第几步、章节引证覆盖率如何。任何阶段都可以「取消规划」或「取消生成」。

### 9.2 读报告

报告正文和问答回答一样带 `[k]` 引用、「（推断）」「【通识】」标签，末尾有参考文献。另外有两块信息值得看：

- **证据强度**：每节标「证据充足」「证据薄弱」或「证据缺失」，让你知道哪些结论站得稳。
- **资料基础**：报告用了多少份资料、类型和年份分布、有多少可区分的独立来源。
  如果你的问题要求「完整枚举所有」，而报告是按相关性检索生成的，这里会明说它没有做完整枚举。

### 9.3 报告的操作

报告卡片上可以：**复制**正文、**下载 .md** 或**下载 zip**（含图片）、**分享**生成免登录只读链接
（第 10.7 节）、**取消分享**、**删除**（二次确认）。

已完成的报告在详情上方还有「就此追问」：切到问答页签、开一个新会话并挂上这份报告，直接在输入框里接着问
（见第 4.3 节）。

### 9.4 报告归谁

报告按**创建者**隔离：在共享笔记本里，每个人只看得到自己建的报告，笔记本的主人也看不到别人的。
想给别人看，用分享链接。任何能读这本笔记本的人都可以建报告。

## 10. 分享与进入群组

笔记本有三种给别人用的方式，都不是实时协同编辑：

| 方式 | 谁能用 | 对方得到什么 |
| --- | --- | --- |
| 分享链接 | 笔记本的主人 | 小笔记本：拷贝一份到自己空间；大笔记本：以只读成员加入 |
| 共享给群组 | 笔记本的主人或管理者 | 组内成员都能打开、提问、写自己的报告、挂为参考库 |
| 公开链接 | 报告或会话的创建者 | 免登录的只读页面，只有那一份报告或那一条会话 |

### 10.1 分享链接

顶栏「分享」打开分享弹窗。上半部分是「链接分享」：

- 点「开启链接分享」生成链接，复制发给对方。只是打开弹窗看看不会生成链接。
- 拿到链接的人登录后会看到笔记本预览。笔记本较小时按钮是「拷贝到我的空间」，得到一份完全独立的副本
  （连 Knowhow 表和参考库挂载一起带过去）；笔记本较大时按钮是「加入(只读)」，以只读成员身份使用原本。
- 「取消链接分享」会让链接失效，**并且把所有只读成员一起移出**，他们在这个笔记本里的检索心得和 Agent
  记录也会清空（个人记忆不删）。点下去会先弹出确认，选「保留链接」就什么都不变。
- 只读成员随时可以在首页卡片上「退出共享」。如果你在这个笔记本里存过记忆，退出时会先告诉你有多少条
  会被永久删除；你可以先「导出为文件」或「转移到其他笔记本」，再点「确认退出并删除」。如果退出中途出了
  问题，界面会告诉你已经删了几条、还剩几条；这时你仍是成员，可以再试一次，接着删完并退出。
- 笔记本所有者取消链接分享、或组管理员把你移出群组，都不会删除你的记忆；重新获得访问后它们还在。

弹窗会提醒一件事：**共享后，本笔记本借入的参考库将暂停参与检索。** 原因见第 10.6 节。

### 10.2 群组是什么

群组是一组用户加上组内角色，用来把知识库共享给一个团队。群组有三种类型，只是标签，权限机制相同：

- **项目组**：任何人都可以建。
- **部门组**、**领域组**：只有系统管理员能建。

组内角色两级：**成员**和**组管理员**。每个组有且只有一个 **owner**（创建者），owner 同时是组管理员，
不能被降级或移出，可以在设置里把 owner 转让给现有成员。

### 10.3 进入群组

两种方式：

- **邀请链接**：组管理员在群组页「成员」页签生成邀请链接发给你，点开登录后自动成为普通成员。
  链接不会自动过期，管理员可以随时换新或撤销。
- **被管理员直接添加**。

### 10.4 群组页

头像菜单「群组」打开群组页。左侧是你加入的群组（可切换看「全部」），右侧四个页签：

- **知识库**：这个组能读的笔记本。你能看到的只有你当前角色实际有读权的那些。owner 和组管理员可以
  「添加知识库」（把自己有管理权的笔记本加进来）或移除，并可选「允许组管理员管理」。
- **成员**：成员列表、邀请链接的生成/复制/换新/撤销、角色调整。
- **共享申请**：见 10.5。
- **设置**：组名、说明、owner 转让、删除群组。

### 10.5 共享自己的笔记本给群组

在笔记本的分享弹窗下半部分「共享给群组」：

- 如果你是这个组的**组管理员**，直接勾选即可生效。可以勾「允许组管理员管理」，让其他组管理员也能
  添加删除来源、整理图谱；但参考库挂载和链接分享永远只有笔记本主人能动。
- 如果你只是这个组的**普通成员**，会变成一条**共享申请**，等组管理员在群组页「共享申请」页签里批准。
  申请待审批时你可以撤回；被驳回后可以重新申请。组管理员的铃铛会提示有待审批申请。

共享给群组的笔记本出现在成员首页的「群组」分区。成员在里面能做什么、不能做什么：

| 能力 | 成员 | 组管理员（被授权管理时） | 笔记本主人 |
| --- | :-: | :-: | :-: |
| 打开、看来源和图谱、提问、存自己的记忆 | ✓ | ✓ | ✓ |
| 建自己的深度报告 | ✓ | ✓ | ✓ |
| 挂为自己笔记本的参考库 | ✓ | ✓ | ✓ |
| 添加 / 删除 / 重新解析来源，整理图谱 | | ✓ | ✓ |
| 修改参考库挂载、开启链接分享 | | | ✓ |

把人移出组、撤销共享、删除组，都会在下一次操作时立刻生效。

### 10.6 参考库：借别人的库来一起检索

在笔记本「设置 → 参考库」里勾选其他笔记本后，这本笔记本提问和写报告时会一并检索它们。
候选分三组：公共知识库、我的笔记本、共享给我的（含群组共享）。原则是**能读就能挂**。

一条重要的限制：**借来的东西不转借。** 如果你把 B 挂进了自己的 A，然后又把 A 分享出去，
B 的内容就会通过 A 被更多人读到，而 B 的主人从没同意过。所以系统规定：
只要 A 被分享出去（有只读成员或共享给了群组），A 借入的参考库就暂停参与检索，设置里会标注
「本笔记本已共享，借来的参考库暂停参与检索；取消本笔记本的共享即可恢复」。
公共知识库和你自己的笔记本不受此限。

### 10.7 公开链接：分享一份报告或一条会话

已完成的深度报告、已完成的问答会话（包括全局会话），创建者都可以生成一个**免登录只读链接**：

- 报告：报告卡片上「分享」。链接形如 `/r/…`。
- 会话：会话里「分享到这条回答」。链接形如 `/c/…`，包含到这条回答为止的全部轮次；之后又有新回答时，
  重新分享可以把水位推进到新回答。

公开页只显示正文、问题、引用和附图，不显示笔记本名。链接可以随时「取消分享」，撤销后打不开。
另外，链接的有效期跟着你的读权走：如果你之后失去了对那本笔记本（或全局会话引用的任何一本）的读权，
链接会暂时打不开，权限恢复后同一个链接自动恢复。

你还可能收到**机器人发来的限时回答链接**（外部 Agent 把回答发进聊天工具时附上的 `/c/…` 链接）。它只显示那一条回答、
页面上写明有效期，无需登录；到期后页面提示「链接已过期，请重新提问」。这类链接不是你生成的，也没有「取消分享」按钮，
想让它失效，需要让令牌的主人撤销令牌或关掉它的回答链接开关。

### 10.8 贡献到公共知识库

如果部署方设置了公共知识库，个人笔记本里的知识对象和记忆可以申请**贡献到公共知识库**。
申请进入管理员的「内容审核」队列（顶栏「分析 → 内容审核」），状态依次是待审核 → 审核中 → 已收录 / 未采纳。
批准时系统会合并重复项再收录到选定的目标库。

## 11. 越用越好

系统会从你的使用中学习，但**学的是「怎么查」和「怎么答」，绝不会扩大它能读什么**。
检索范围永远只由你的勾选决定。这一章说明它学了什么、你在哪里能看到和干预。

### 11.1 AI 对这个库的理解

左栏「添加来源」旁边有一个「AI 对这个库的理解」按钮，打开的面板里第一张卡就是它。系统会定期整理三段简短的描述：
这个库大致收了哪类资料、反复出现的关键名字和主题、已经看出来的空缺（比如没有表格或公式、
某些文档解析质量有警告）。每段下面列出它的依据，点一下就能打开对应的资料。

这份理解会作为背景提供给「逐步推理」的规划阶段，帮它更快找对方向；它**不是证据**，不会出现在回答里。
笔记本的管理者可以直接编辑这些描述，改过的内容系统不会覆盖；不再成立的描述系统会自己撤回。

### 11.2 我的检索心得

同一面板的第二张卡，只有你自己看得见、只在你自己提问时生效。系统从你在这本笔记本里的提问记录中总结
两件事：哪些查法对这个库有效、哪些提问没找到结果。你也可以手写。它同样只影响怎么检索。

### 11.3 检索经验

第三张卡是系统从已完成的提问中离线提炼出来的**检索打法**：在某类问题形态下，某个检索动作值得用或不值得用。
它按笔记本分区，条目里不包含任何问题原文或来源名。「逐步推理」每次规划和反思时会自动收到最相关的几条；
模型也可以在反思时主动「回想」一次，去查更多经验，这一步会在推理轨迹里显示为「回想以往的查法」。
面板上可以「整理」或「清空」。

### 11.4 我的回答偏好

头像菜单「我的回答偏好」里有四项：**回答语言**（自动 / 中文 / 英文）、**组织方式**（自动 / 要点 / 先表格 /
散文）、**详略**（自动 / 简洁 / 详细）、**常用术语**（最多 10 条）。它们只影响回答怎么组织和措辞，不影响检索。

系统会根据你最近提问的语言自动推断「回答语言」，推断值旁有「设为你的选择」按钮可以固化；
你自己设过的项系统永远不会改。任何一项都可以「恢复自动」。

### 11.5 反馈按钮

每条回答下的「有帮助 / 没帮助」会被记录下来。它目前不直接改变检索，而是让管理员在看板里看到
哪些问题答得不好，从而补资料、调配置。多点，问题更容易被发现。

### 11.6 记忆

第 8.1 节的记忆是最直接的「越用越好」：你确认过的回答会成为后续提问的优先证据，
优先级高于普通原文，低于公共知识库。

## 12. 其他页面

### 12.1 Agent 接入（`/agents`）

如果你用 Claude Code、Codex 一类的编程助手，可以在这里签发一个访问令牌，让它们通过 MCP 协议
在你的笔记本里提问、查资料、提交候选记忆。令牌可以限定能访问哪些笔记本、能做哪些动作、什么时候过期，
签发后也能原地修改。详细接入步骤见[Agent MCP 与 Memory 接入](./agent-mcp-memory-sop_zh.md)。
勾选「读取」的 Agent 还能读你自己的问答记录和深度报告，只限它能访问的笔记本。
勾选「管理」后，Agent 还能新建笔记本，新库会自动加入当前凭证的授权范围，也会出现在你的笔记本列表中。

勾选「问答」后，还可以单独打开「允许签发限时回答链接」。打开后，这个 Agent 可以把它的回答发成一条限时链接
（例如贴进群聊或工单），拿到链接的人**无需登录**就能看完整回答，其中可能包含引用到的个人记忆摘录，所以只给确实
需要的令牌打开。链接到期后会提示重新提问；撤销这个令牌，或关掉它的开关，它发出的链接会立即打不开。

### 12.2 许愿墙（`/wishes`）

反馈问题、提功能需求的地方。写标题和详细说明发布，给别人的心愿点赞。管理员会在这里发布更新计划、
标记处理状态。等待回答或报告生成时，等待区会轮播展示大家的心愿。

### 12.3 模型服务

顶栏「模型服务」只显示当前模型服务是否正常。模型由部署方统一配置，普通用户不需要也不能改。
显示「模型服务不可用」时，上传和浏览仍然可用，但问答、图谱整理、报告生成会失败或降级，请联系管理员。

### 12.4 管理员页面

以下页面只有管理员能进：

- `/admin/usage` 用户使用总览：各用户的笔记本、来源、提问、报告数量，调整文档上限，授予或撤销管理员角色，
  停用/启用账号、修改用户名（不能改自己和内置管理员；统一认证下帮用户纠正误选的新账号就用这两项）。
- `/admin/questions` 提问分析：跨用户查看问答和报告的原始提问。
- `/admin/extensions` 已加载的扩展：查看部署装入的插件。
- `/dev/logs` 日志查看：活动流与诊断日志。

## 13. 常见问题

**上传后一直显示「解析中」。**
大文件和扫描件解析需要时间，也要排队。打开「看板」看整体进度。长时间不动可以在来源详情里点「重新解析」。

**回答说「证据不足」或全是「（推断）」。**
说明文档里确实没有直接答案。可以：换个问法、检查检索范围是不是勾少了、把相关文档补上传、
或者换「逐步推理」的更高档位。系统宁可说不知道，也不会编。

**回答引用的段落不是我想要的那篇。**
在左栏取消勾选无关来源，或用引号把关键短语括起来（第 4.4 节）。

**我看不到引擎选择和来源复选框。**
你在自动模式。头像菜单里打开「高级模式」。

**「整理知识图谱」按钮是灰的 / 一直在跑。**
整理要调用模型；模型服务不可用时无法整理。文档很多时整理会跑很久，「看板」里能看到进度。
不整理也能正常问答。

**群组共享的笔记本我怎么退出？**
退不了，也不需要退：它由组管理员管理，你不想看可以让管理员把你移出组或撤销共享。

**参考库标着「暂停参与检索」。**
你的笔记本被分享出去了，借入的参考库按规则暂停（第 10.6 节）。取消分享即恢复。

**分享链接对方打不开（404）。**
报告或会话链接被撤销了，或者你已失去对相关笔记本的读权。笔记本链接则可能已被主人取消分享。

**深度报告停在「待确认」。**
它在等你确认问题理解或分析框架，铃铛里有入口。只有创建者能确认。

**我提交的问题有没有上限？**
问题正文最多 4000 字，会话标题最多 200 字，超出会拦住提交，不会被截断。

**我的记忆同事能看到吗？**
不能。记忆只有创建者本人可见，共享笔记本也一样。
