# P4:KG 收缩到「按需 · 严格推理」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development 逐任务实施。步骤用 `- [ ]` 复选框追踪。每任务 TDD(先写失败测试 → 跑红 → 最小实现 → 跑绿 → commit)。

**Goal:** 把 KG 抽取改为按需(默认关)、删冗余模式 fast/global、为严格推理(reasoning/graph)接通现有 two-tier 联邦,并在无图时显式门控。

**Architecture:** 摄取默认只建 chunk(`KG_AUTO_EXTRACT=false`),KG 经"建图"端点/离线 CLI 按需构建(复用独立的 `_run_extraction`)。严格推理可用性 = 本 notebook 有 KG ∨ 存在 `tier='base'` 且有 KG 的笔记本;检索把 reasoning/graph 从单库 `_retrieve_scored` 切到现有(休眠的)`federated_retrieve`,激活 base∪active 联邦。删 fast/global 处理器与注册,退役 id 映射到 chunk。

**Tech Stack:** Python/FastAPI/SQLite、pydantic-settings、pytest。基于 spec `docs/superpowers/specs/2026-06-16-p4-kg-shrink-design.md`。

> 行号取自 worktree `worktree-p4-kg-shrink` 快照,实施时按当时代码复核。测试统一复用现有 `repo` fixture 写法(见 `backend/tests/test_cross_tier_reasoning.py` / `test_kg_repository.py`):`monkeypatch.setenv` DATABASE_URL/STORAGE_DIR/LLM_LOG_ENABLED → `SQLiteRepository(Settings())` → `r.embedder = FakeEmbedder(dim=16)`。直接种 KG 用 `repo.store_kg(nb_id, source_id_or_None, objects, relations)`(object: `{"local_id","object_type","payload":{"name",...},"evidence":[]}`)。

```python
    def build_notebook_kg(self, notebook_id: str) -> dict:
        """按需对该 notebook 下"尚无 KG"的 source 逐个抽取(复用 _run_extraction)。
        幂等:已有 knowledge_objects 的 source 跳过。无 LLM → RuntimeError。
        单 source 失败隔离,不连累其余、不回退其终态,错误入 event log。"""
        self.get_notebook(notebook_id)  # KeyError if missing
        if not getattr(self.llm_client, "configured", False):
            raise RuntimeError("LLM not configured; cannot build KG")
        with self._connect() as db:
            src_rows = db.execute(
                "SELECT id FROM sources WHERE notebook_id = ?", (notebook_id,)
            ).fetchall()
            kgful = {r["source_id"] for r in db.execute(
                "SELECT DISTINCT source_id FROM knowledge_objects "
                "WHERE notebook_id = ? AND source_id IS NOT NULL", (notebook_id,)
            ).fetchall()}
        targets = [r["id"] for r in src_rows if r["id"] not in kgful]
        done, failed = [], []
        for sid in targets:
            try:
                self._set_source_status(sid, "extracting")
                self._run_extraction(sid)
                self._set_source_status(sid, "extracted")
                done.append(sid)
            except Exception as exc:  # noqa: BLE001 — 隔离单 source 失败
                failed.append(sid)
                self.event_log.logger.exception("build_notebook_kg failed for %s", sid)
        try:
            self._mark_unified_kg_dirty(notebook_id)
        except Exception:
            self.event_log.logger.exception("unified-KG dirty mark failed for %s", notebook_id)
        return {"built": done, "failed": failed, "skipped": list(kgful)}
```
> 列名核对:`sources` 表主键/`knowledge_objects.source_id` 实际列名按 schema 调整(`build_notebook_kg` 上方已有同类查询可参照)。

```python
    def _any_base_notebook_has_kg(self) -> bool:
        """True iff some tier='base' notebook has any knowledge_objects."""
        with self._connect() as db:
            row = db.execute(
                "SELECT EXISTS(SELECT 1 FROM knowledge_objects ko "
                "JOIN notebooks nb ON nb.id = ko.notebook_id WHERE nb.tier='base')"
            ).fetchone()
        return bool(row[0])

    def notebook_kg_state(self, notebook_id: str) -> str:
        """派生 KG 态(不落库):building/ready/partial/none。"""
        with self._connect() as db:
            srcs = [r["status"] for r in db.execute(
                "SELECT status FROM sources WHERE notebook_id = ?", (notebook_id,)).fetchall()]
            kg_src = {r["source_id"] for r in db.execute(
                "SELECT DISTINCT source_id FROM knowledge_objects "
                "WHERE notebook_id = ? AND source_id IS NOT NULL", (notebook_id,)).fetchall()}
            has_any = bool(db.execute(
                "SELECT EXISTS(SELECT 1 FROM knowledge_objects WHERE notebook_id = ?)",
                (notebook_id,)).fetchone()[0])
        if any(s == "extracting" for s in srcs):
            return "building"
        if not has_any:
            return "none"
        extractable = [s for s in srcs if s != "failed"]
        # 所有可抽 source 都有 KG → ready;否则 partial。
        all_covered = extractable and len(kg_src) >= len(extractable)
        return "ready" if all_covered else "partial"
```
